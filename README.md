# Colorline Photography MW

This repository contains a production-ready Next.js + TypeScript + Tailwind website scaffold built for Colorline Photography MW. It includes pages, components, responsive styles and simple form handling via mailto (no backend required). Replace the placeholder images in /public/images with your own photography.

To run locally:

1. npm install
2. npm run dev

Notes:
- Forms use mailto by default. If you'd like server-side email delivery, provide credentials for a transactional email provider and I will add a secure API route.
- I did not add any videography sections or pricing anywhere on the site.
