# Images

Place your high-quality Colorline Photography images inside the `/public/images/` folder. Filename suggestions used by the template so replacing is straightforward:

- placeholder-hero.jpg (recommended: landscape, large, used on home hero)
- placeholder-portrait.jpg (portrait oriented)
- placeholder-vertical.jpg
- placeholder-1.jpg...placeholder-8.jpg
- placeholder-2.jpg
- placeholder-3.jpg

Use large images (2000-4000px) for best results; Next/Image will serve responsive sizes and webp/avif when possible.

Alt text: When you replace images, keep the descriptive alt text in the components for accessibility.
